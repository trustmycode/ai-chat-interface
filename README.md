# Демонстрационный интерфейс чата

Учебное приложение на Next.js 15 и React 19: регистрация, вход через NextAuth, список диалогов, Markdown-сообщения и выбор оформления модели. Ответы модели **имитируются локально**; внешние API OpenAI и Anthropic не вызываются.

## Граница применения

Проект подходит для локальной демонстрации интерфейса и проверки пользовательского потока. Он не предназначен для настоящих переписок и многопроцессной эксплуатации:

- данные хранятся в атомарно заменяемом JSON-файле на пользователя;
- блокировка конкурентных изменений действует только внутри одного процесса Node.js;
- ограничения частоты хранятся в памяти одного процесса;
- нет настоящего вызова модели, потоковой выдачи и учёта стоимости;
- для промышленной версии нужна транзакционная база, общее хранилище ограничений и внешний поставщик модели.

## Безопасность демонстрационной версии

- `NEXTAUTH_SECRET` обязателен: без него вход и серверные маршруты возвращают ошибку конфигурации;
- UUID чата создаётся криптографическим генератором;
- хранилище разделено по пользователям, поэтому чтение, изменение и удаление всегда проверяют владельца;
- регистрация и сообщения имеют предел размера и частоты;
- сообщения ограничены последними 100 элементами;
- файлы записываются через временный файл и атомарное переименование с правами `0600`;
- локальный каталог `data` исключён из Git.

Старые демонстрационные данные удалены из текущей версии, но могли остаться в истории Git. Их нельзя считать секретными; связанные пароли необходимо заменить.

## Запуск

Требуется Node.js 22.

```bash
cp .env.example .env.local
```

Создайте длинный случайный `NEXTAUTH_SECRET`, затем выполните:

```bash
npm ci
npm run dev
```

Приложение доступно на `http://127.0.0.1:3000`.

## Проверки

```bash
npm test
NEXTAUTH_SECRET=test-only-secret-with-at-least-32-characters npm run build
```

Проверки покрывают атомарное состояние чата, изоляцию владельцев, параллельную регистрацию и удаление сообщений. GitHub Actions дополнительно выполняет чистую установку, производственную сборку и сборку контейнера.

## Контейнер

```bash
docker build -t ai-chat-interface .
docker run --rm \
  -p 127.0.0.1:3000:3000 \
  -e NEXTAUTH_URL=http://127.0.0.1:3000 \
  -e NEXTAUTH_SECRET=replace-with-a-long-random-value \
  -v ai-chat-data:/app/data \
  ai-chat-interface
```

Не публикуйте контейнер в открытой сети как производственный сервис.
